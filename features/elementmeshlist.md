# Element Mesh List

Inventory of **Three.js element meshes** for the Wf type schematic. The Taxonomy section is the meaning of the four scales.

**Scenes:** `wf` (`src/core/wfSchematic.ts`, pin at 18.601312°N, 92.674937°W), `asym` (`src/core/asymWfSchematic.ts`, pin at Sfântu Gheorghe), and `tfw` (`src/core/tfwEcsSchematic.ts`, pin at −19.984295231442236, 119.165775381814, panel `TfwECSschematic.tsx`). All three render in [`src/ui/WfSchematicView.tsx`](../src/ui/WfSchematicView.tsx) via `geometryFor()`. Layout, ranks, nested poses, yaw, and explode come from core `sceneAt(explode)` — meshes do not choose where they sit.

**Axes:** +X alongshore (right flank), +Y up, +Z seaward. Land is −Z; the channel sits on the axis.

## Taxonomy

Four scales, fine to coarse. Use these codes everywhere in this file. **E** is one drawable mesh. **ES** and **EC** are groupings of those meshes. **ECS** is one scene. The water slab is the ground mesh of the **ECS** (body `ecs`).

“Top set”, “mid set”, and “toe set” in the geometry column are the three thickness bands of one beach-ridge cross-section. They are not element sets.

| Code | Rank | Meaning |
| --- | --- | --- |
| **E** | `element` | One drawable mesh: a channel, a mouth bar, a beach ridge, a swale, a shale, or a delta plain. |
| **ES** | `element-set` | One set of elements. A mouth-bar element set is three mouth bars. A beach-ridge element set is one beach ridge, plus the shale on its landward side and the swale, where that gap exists. |
| **EC** | `element-complex` | One full complex of element sets. A beach-ridge element complex is one full flank: every ridge, swale, and shale of that flank. All components of one symmetric beach ridge are one element complex, and an asymmetric flank or a convex-seaward flank is its own. A mouth-bar element complex is one full fan: proximal, mid, or distal. |
| **ECS** | `element-complex-set` | One full scene, as the scenes are defined now (`wf`, `asym`, or `tfw`). |

Scene-graph ids (`es-ridge-l`, `ec-mouth`, `ecs`, and the rest) are the labels in `sceneAt`. The `rank` on those groups is the coarser label the code still stores. `es-ridge-l` is `rank: element-set` and holds a whole flank; under this section that flank is one **EC** made of five **ES**. `es-mouth` in `wf` holds two fans. Each element set keeps the group id already stored for that fan or flank. The Scale column follows the meanings above.

**Beach-ridge element set.** Ridges on a flank are indexed **0** landward through **4** seaward. The swale and shale index is the landward ridge of that gap. Ridge **0** is an element set on its own. Ridge **i** (1–4) is an element set with `e-swale-*-{i−1}` and `e-shale-*-{i−1}`. Five element sets per flank: one of 1 element and four of 3. That is 13 elements, and that flank is one element complex.

**Mouth-bar element set.** Each fan has nine mouth bars, so each fan is three element sets and one element complex. The scale reads the bars in id-index order: **0–2**, **3–5**, **6–8**. The fan template is not stored as three rows, and those three sets share the fan’s group id.
